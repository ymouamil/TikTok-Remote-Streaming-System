## Script

This system allows remote hosts to appear on a TikTok livestream without needing access to the TikTok account.

The host joins through Discord and shares their screen.

The operator captures the Discord feed in TikTok LIVE Studio and broadcasts it from the main TikTok account.

Viewers type in TikTok chat. The operator shares the chat window back to the hosts through Discord. The hosts read chat and respond verbally.

The basic workflow is:

Remote Host → Discord → Operator Computer → TikTok LIVE Studio → TikTok Live

The chat workflow is:

TikTok Chat → Operator → Discord Screen Share → Hosts
