# Video Script 3: Operator Setup

[← Back to Home](../../README.md)

---

## Goal

Show the operator how to prepare the stream.

---

## Script

Open Discord.

Open TikTok LIVE Studio.

Ask the host to join Discord and share their screen.

In TikTok LIVE Studio, select Discord as the screen or window capture source.

Check the preview.

If the Discord sidebars are visible, make the shared screen full screen or use OBS to crop the Discord window.

Before going live, confirm that video, audio, and chat sharing all work.
