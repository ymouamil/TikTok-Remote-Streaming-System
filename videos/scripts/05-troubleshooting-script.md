# Video Script 5: Troubleshooting

[← Back to Home](../../README.md)

---

## Goal

Explain common problems.

---

## Script

If the host video is not showing, check that the host is still sharing their screen.

If there is no audio, check the host microphone and Discord mute settings.

If there is echo, make sure everyone is wearing headphones.

If TikTok LIVE Studio shows the full Discord interface, use full-screen mode or OBS cropping.

If hosts cannot see chat, restart the Discord chat screen share.
