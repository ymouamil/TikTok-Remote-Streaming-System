# Video Script 4: Chat Workflow

[← Back to Home](../../README.md)

---

## Goal

Show how hosts read TikTok chat.

---

## Script

When the stream is live, TikTok LIVE Studio shows a chat panel.

The operator keeps the chat panel visible.

Then the operator shares the chat window through Discord.

All remote hosts in the Discord call can read the same TikTok chat.

Hosts do not need to type in TikTok chat. They read viewer comments and respond verbally during the livestream.
