# FAQ

[← Back to Home](../README.md)

---

## Do hosts need TikTok accounts?

No. In this workflow, the operator streams from one TikTok account.

Hosts join through Discord.

---

## Do hosts need TikTok LIVE access?

No. Only the TikTok account being used by the operator needs LIVE access.

---

## Can hosts read chat?

Yes. The operator shares the TikTok chat window back to hosts through Discord.

---

## Can hosts type in TikTok chat?

Not in Version 1.

Version 1 is designed for hosts to read chat and respond verbally.

---

## Can multiple hosts join?

Yes. Multiple hosts can join the same Discord call.

---

## What if Discord shows sidebars?

Use fullscreen mode or OBS cropping.

---

## Is OBS required?

No for the simplest version.

Yes if you want:

- Cropping
- Overlays
- Branding
- Multiple host layouts
- Better production quality

---

## Is a database required?

No.

A database is unnecessary for this first project.

---

## Is custom software required?

No.

The first version can be done with Discord and TikTok LIVE Studio.

---

## What is the final deliverable?

Recommended final deliverable:

- Working setup
- Screenshots
- Short walkthrough video
- This documentation repository
