# Installation Guide

[← Back to Home](../README.md)

---

## Purpose

This guide explains what software must be installed before using the TikTok Remote Streaming System.

---

## Operator Software

The operator is the person controlling the stream from the main computer.

### 1. Discord

Discord is used to communicate with remote hosts and receive their screen shares.

Download:

[Download Discord](https://discord.com/download)

Screenshot placeholder:

![Discord Download](../images/discord-download.png)

Checklist:

- [ ] Discord installed
- [ ] Operator logged in
- [ ] Discord server or call created
- [ ] Host invited

---

### 2. TikTok LIVE Studio

TikTok LIVE Studio is used to broadcast the stream to TikTok.

Download TikTok LIVE Studio from the official TikTok LIVE/Creator dashboard for the account being used.

Checklist:

- [ ] TikTok LIVE Studio installed
- [ ] Operator logged into TikTok account
- [ ] Stream preview visible
- [ ] Discord source added or selected

---

### 3. OBS Studio Optional

OBS is optional for the simplest version, but recommended if you need better cropping, overlays, branding, or multi-host layouts.

Download:

[Download OBS Studio](https://obsproject.com/download)

Checklist:

- [ ] OBS installed
- [ ] Scenes created
- [ ] Discord captured
- [ ] OBS Virtual Camera tested

---

## Host Software

The host is the remote person appearing on the stream.

### Required

Hosts only need:

[Download Discord](https://discord.com/download)

Checklist:

- [ ] Discord installed
- [ ] Host logged in
- [ ] Host joined call
- [ ] Host can share screen
- [ ] Host can hear operator

---

## Optional Tools

### VDO.Ninja

VDO.Ninja can be used for a cleaner remote video feed than Discord.

Open:

[VDO.Ninja](https://vdo.ninja/)

Documentation:

[VDO.Ninja Documentation](https://docs.vdo.ninja/)

---

## Success Criteria

Installation is complete when:

- [ ] Operator can open Discord
- [ ] Operator can open TikTok LIVE Studio
- [ ] Host can join Discord
- [ ] Host can share their screen
- [ ] TikTok LIVE Studio can see the Discord feed
