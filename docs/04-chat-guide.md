# Chat Sharing Guide

[← Back to Home](../README.md)

---

## Goal

Hosts need to read TikTok viewer comments so they can respond verbally on stream.

They do not need to type into TikTok chat.

---

## Simple Chat Workflow

```text
TikTok Viewers
     ↓
TikTok LIVE Studio Chat Panel
     ↓
Operator Shares Chat Through Discord
     ↓
Remote Hosts Read Chat
     ↓
Hosts Respond Verbally
```

---

## Step 1: Open TikTok Chat

When the stream is live, TikTok LIVE Studio will show a chat panel.

Screenshot placeholder:

![Chat Window](../images/chat-window.png)

---

## Step 2: Share Chat To Hosts

In Discord:

1. Click **Share Screen**.
2. Select the TikTok LIVE Studio window or chat window.
3. Ask hosts if they can see chat.
4. Keep the chat visible during the stream.
