# Troubleshooting Guide

[← Back to Home](../README.md)

---

## Problem: TikTok LIVE Studio Shows Discord Sidebars

Cause:

TikTok LIVE Studio is capturing the entire Discord window.

Fix:

- Make Discord screen share full screen.
- Hide panels if possible.
- Use OBS to crop the Discord window.
- Capture only the shared screen area if available.

---

## Problem: Host Video Not Showing

Check:

- Host is in the call
- Host is sharing screen
- Correct Discord window selected
- TikTok LIVE Studio preview is active

---

## Problem: No Audio

Check:

- Host microphone selected
- Host is not muted
- Discord audio working
- TikTok LIVE Studio audio source selected
- Computer volume not muted

---

## Problem: Echo

Cause:

Microphone is picking up speaker sound.

Fix:

- Hosts must wear headphones.
- Operator should wear headphones.
- Mute duplicate audio sources.

---

## Problem: Host Cannot See Chat

Fix:

1. Operator opens TikTok chat.
2. Operator shares chat window through Discord.
3. Host confirms they can read messages.

---

## Problem: Black Screen

Try:

- Restart Discord screen share.
- Restart TikTok LIVE Studio.
- Ask host to share a different window.
- Use OBS as a capture middle layer.

---

## Problem: Stream Looks Messy

Fix:

- Use OBS.
- Crop Discord.
- Add a clean background.
- Add host name labels.
- Use a simple layout.
