# GitHub Commands

[← Back to Home](../README.md)

---

## Create Project Folder

```powershell
mkdir TikTok-Remote-Streaming-System
cd TikTok-Remote-Streaming-System
```

---

## Initialize Git

```bash
git init
git branch -M main
```

---

## Add Files

```bash
git add .
git commit -m "Initial TikTok remote streaming documentation"
```

---

## Connect To GitHub

Create a new repository on GitHub.

Then run:

```bash
git remote add origin https://github.com/YOUR_USERNAME/TikTok-Remote-Streaming-System.git
```

Replace `YOUR_USERNAME` with your actual GitHub username.

---

## Push Project

```bash
git push -u origin main
```

---

## Every Time You Update Files

```bash
git add .
git commit -m "Update documentation"
git push
```
